# docs/METODOLOGIA.md
## Metodología de Desarrollo

### Arquitectura del Sistema
- Frontend: React + TypeScript para tipado seguro
- Backend: FastAPI + TensorFlow para inferencia
- Estilos: Tailwind CSS + Framer Motion para animaciones

### Decisiones Técnicas
1. **MobileNetV2**: Optimizado para dispositivos móviles
2. **FastAPI**: Alto rendimiento y documentación automática
3. **React**: Componentización y estado reactivo
